## OpenAI 兼容 API

内置 HTTP 服务可让任何 OpenAI 兼容客户端调用你的本地模型。默认端点为：

```
http://<设备IP>:8080/v1/chat/completions
```

在应用设置中启动服务后，即可在同一 Wi-Fi 下的其他设备上调用。

### 1. cURL —— 非流式

```bash
curl http://<设备IP>:8080/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
        "model": "gemma",
        "messages": [
            {"role": "system", "content": "你是应急救援助手"},
            {"role": "user", "content": "地震后如何判断建筑是否安全？"}
        ]
    }'
```

### 2. cURL —— 流式

```bash
curl http://<设备IP>:8080/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
        "model": "gemma",
        "stream": true,
        "messages": [
            {"role": "user", "content": "你好"}
        ]
    }'
```

### 3. OpenAI SDK（Node.js）

```javascript
import OpenAI from "openai";

const client = new OpenAI({
    apiKey: "local", // 本地服务不校验，仅作占位
    baseURL: "http://<设备IP>:8080/v1",
});

const completion = await client.chat.completions.create({
    model: "gemma",
    messages: [
        { role: "user", content: "洪水期间如何净化饮用水？" },
    ],
});

console.log(completion.choices[0].message.content);
```

### 注意事项

- 请将 `<设备IP>` 替换为实际设备的 IP 地址。
- 流式与非流式的区别在于 `stream: true` 参数。
- 本地服务不需要真实 API Key，任意占位符即可。
- 也可将 **ChatBox**、**Open WebUI** 等客户端的接口地址指向同一 base URL，把手机当作它们的模型后端。

## 常见问题

**真的能离线使用吗？**
可以。只要模型已在设备上，推理就完全在本机进行，无需 Wi-Fi 或流量，飞行模式下也能用。

**需要注册账号吗？**
不需要。没有注册、没有登录，也不做任何追踪。

**可以使用哪些模型？**
Gemma 4、Qwen 3.5、内置模型、系统内置 AI（如支持），以及你自行导入的任意 `.litertlm` 模型。

**我的对话保存在哪里？**
仅保存在你的设备上（本地数据库）。使用**隐私模式**可让对话只存在于内存中，不保存任何历史。

**其他应用能调用我手机上的模型吗？**
可以。启用 OpenAI 兼容服务后，在同一网络下把任意兼容客户端的地址指向 `http://<设备IP>:8080/v1` 即可。

**模型加载失败怎么办？**
打开**设置**重新安装模型，并导出日志以便排查；部分设备上切换计算后端（CPU/GPU）也有帮助。
